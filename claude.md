# 📌 Проект: Платформа перераспределения органических отходов

---

# 1️⃣ Описание проекта

Цифровая платформа, предназначенная для соединения предприятий общественного питания и частных хозяйств (фермеров) с целью перераспределения органических пищевых отходов.

Система выполняет функцию информационного посредника и обеспечивает цифровое сопоставление спроса и предложения.

Коммуникация между сторонами осуществляется напрямую вне системы.

---

# 2️⃣ Актуальность проекта

- Рост количества предприятий общественного питания
- Увеличение объема пищевых отходов
- Высокая стоимость кормов для частных хозяйств
- Отсутствие цифровых инструментов перераспределения отходов

Проект способствует:

- снижению нагрузки на полигоны
- поддержке сельского хозяйства
- цифровизации процессов взаимодействия

---

# 3️⃣ Проблематика

## Для ресторанов:

- Платный вывоз отходов
- Отсутствие системного перераспределения
- Нет цифрового учета отходов

## Для фермеров:

- Высокая стоимость кормов
- Нехватка кормов в определённые периоды
- Отсутствие информации о доступных источниках

---

# 4️⃣ Цель проекта

Разработка информационной системы для цифрового сопоставления поставщиков органических отходов и их потенциальных потребителей.

---

# 5️⃣ Задачи проекта

- Разработать архитектуру платформы
- Спроектировать структуру базы данных
- Реализовать регистрацию пользователей
- Реализовать публикацию объявлений
- Реализовать фильтрацию предложений
- Обеспечить удобный пользовательский интерфейс

---

# 6️⃣ Целевая аудитория

## Поставщики:

- Рестораны
- Кафе
- Столовые

## Получатели:

- Фермеры
- Частные хозяйства
- Владельцы домашнего скота

---

# 7️⃣ Бизнес-модель

### Основная модель:

B2B подписка для предприятий общественного питания.

### Дополнительные модели:

- Платное приоритетное размещение объявлений
- Freemium-модель (ограниченное количество бесплатных публикаций)

Монетизация реализуется на уровне доступа к функционалу платформы.

---

# 8️⃣ User Flow

## Роль: Ресторан

1. Регистрация
2. Вход в личный кабинет
3. Создание объявления:
    - Тип отходов
    - Объём
    - Район
    - Периодичность
    - Контактные данные
4. Публикация
5. Ожидание звонков

---

## Роль: Фермер

1. Регистрация
2. Просмотр предложений
3. Фильтрация по:
    - Району
    - Типу отходов
    - Объёму
4. Просмотр контактной информации
5. Связь напрямую по телефону

---

# 9️⃣ Функциональные требования

- Регистрация и авторизация пользователей
- Разделение ролей (Restaurant / Farmer)

- Просмотр списка объявлений
- Фильтрация
- Просмотр контактной информации
